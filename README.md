# LuxFurnish - Premium Furniture Store

A full-stack web application with a Single-Page Application (SPA) frontend for browsing and purchasing premium furniture.

## Tech Stack

### Frontend
- React (Vite)
- React Router
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB

## Features

- Browse furniture products
- View detailed product information
- Client-side routing with React Router
- Responsive UI with Tailwind CSS
- RESTful API for data handling

## Running Locally

```bash
# Clone the repository
git clone https://github.com/VladislavAndonov/LuxFurnish
cd LuxFurnish

# Install dependencies for server and client
npm --prefix server install
npm --prefix client install

# Start the development server
npm --prefix server start

# Start the client
npm --prefix client run dev
```

> Make sure to set up your `.env` file with your MongoDB connection string and JWT secret before running.
